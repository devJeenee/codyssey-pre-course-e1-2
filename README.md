# Python 기초 퀴즈 게임

## 프로젝트 개요

Python 기본 문법으로 만든 4지선다형 콘솔 퀴즈 게임입니다.
메뉴에서 퀴즈를 풀거나 새로운 문제를 추가하고, 문제 목록과 최고 점수를 확인할 수 있습니다.
퀴즈와 최고 점수는 `state.json`에 저장되므로 프로그램을 종료한 뒤 다시 실행해도 유지됩니다.

## 퀴즈 주제와 선정 이유

퀴즈 주제는 **Python 기초 문법**입니다.
변수와 `int`, `bool`, `list`, `dict` 같은 기본 자료형은 이후 Python 학습의 기초가 되기 때문에 반복해서 확인할 수 있도록 이 주제를 선택했습니다.
프로그램에는 직접 작성한 기본 퀴즈 5개가 포함되어 있습니다.

## 실행 방법

### 실행 환경

- Python 3.10 이상
- 외부 라이브러리 없음

### 저장소 내려받기 및 실행

```bash
git clone https://github.com/devJeenee/codyssey-pre-course-e1-2.git
cd codyssey-pre-course-e1-2
python3 main.py
```

프로그램을 실행하면 다음 메뉴가 나타납니다.

```text
========================================
       Python 기초 퀴즈 게임
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
```

### 클래스 역할

- `Quiz`: 문제, 선택지 4개, 정답을 저장하고 문제 출력과 정답 확인을 담당합니다.
- `QuizGame`: 메뉴, 입력 처리, 퀴즈 진행, 추가, 목록, 최고 점수, 파일 저장과 불러오기를 담당합니다.
- `main.py`: 게임을 시작하고 입력 중단 상황에서 데이터를 저장한 뒤 안전하게 종료합니다.

## 데이터 파일 설명

데이터는 프로젝트 루트의 `state.json`에 UTF-8 JSON 형식으로 저장됩니다.

```json
{
    "quizzes": [
        {
            "question": "정수 42의 자료형은 무엇일까요?",
            "choices": ["str", "bool", "int", "list"],
            "answer": 3
        }
    ],
    "best_score": null
}
```

| 필드 | 설명 |
| --- | --- |
| `quizzes` | 퀴즈 목록 |
| `question` | 문제 문자열 |
| `choices` | 4개의 선택지 목록 |
| `answer` | 1~4 범위의 정답 번호 |
| `best_score` | 0~100 범위의 최고 점수, 기록이 없으면 `null` |

- 파일이 없으면 기본 퀴즈 5개로 `state.json`을 새로 만듭니다.
- JSON이 손상되었거나 데이터 형식이 잘못되면 안내 후 기본 데이터로 복구합니다.
- 파일을 읽거나 쓸 수 없는 경우에는 오류 메시지를 출력하고 가능한 범위에서 실행을 계속합니다.
