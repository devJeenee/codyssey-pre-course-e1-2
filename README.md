# Python 기초 퀴즈 게임

## 프로젝트 개요

Python 기본 문법으로 만든 4지선다형 콘솔 퀴즈 게임입니다.
메뉴에서 퀴즈를 풀거나 새로운 문제를 추가하고, 문제 목록과 최고 점수를 확인할 수 있습니다.
퀴즈와 최고 점수는 `state.json`에 저장되므로 프로그램을 종료한 뒤 다시 실행해도 유지됩니다.

## 퀴즈 주제와 선정 이유

퀴즈 주제는 **Python 기초 문법**입니다.
변수와 `int`, `bool`, `list`, `dict` 같은 기본 자료형은 이후 Python 학습의 기초가 되기 때문에 반복해서 확인할 수 있도록 이 주제를 선택했습니다.
프로그램에는 직접 작성한 기본 퀴즈 5개가 포함되어 있습니다.

## 실행 방법

### 실행 환경

- Python 3.10 이상
- 외부 라이브러리 없음

### 저장소 내려받기 및 실행

```bash
git clone https://github.com/devJeenee/codyssey-pre-course-e1-2.git
cd codyssey-pre-course-e1-2
python3 main.py
```

프로그램을 실행하면 다음 메뉴가 나타납니다.

```text
========================================
       Python 기초 퀴즈 게임
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
```

### 클래스 역할

- `Quiz`: 문제, 선택지 4개, 정답을 저장하고 문제 출력과 정답 확인을 담당합니다.
- `QuizGame`: 메뉴, 입력 처리, 퀴즈 진행, 추가, 목록, 최고 점수, 파일 저장과 불러오기를 담당합니다.
- `main.py`: 게임을 시작하고 입력 중단 상황에서 데이터를 저장한 뒤 안전하게 종료합니다.

## 데이터 파일 설명

데이터는 프로젝트 루트의 `state.json`에 UTF-8 JSON 형식으로 저장됩니다.

```json
{
    "quizzes": [
        {
            "question": "정수 42의 자료형은 무엇일까요?",
            "choices": ["str", "bool", "int", "list"],
            "answer": 3
        }
    ],
    "best_score": null
}
```

| 필드 | 설명 |
| --- | --- |
| `quizzes` | 퀴즈 목록 |
| `question` | 문제 문자열 |
| `choices` | 4개의 선택지 목록 |
| `answer` | 1~4 범위의 정답 번호 |
| `best_score` | 0~100 범위의 최고 점수, 기록이 없으면 `null` |

- 파일이 없으면 기본 퀴즈 5개로 `state.json`을 새로 만듭니다.
- JSON이 손상되었거나 데이터 형식이 잘못되면 안내 후 기본 데이터로 복구합니다.
- 파일을 읽거나 쓸 수 없는 경우에는 오류 메시지를 출력하고 가능한 범위에서 실행을 계속합니다.

## 입력 및 예외 처리

프로그램을 직접 실행하여 재현할 수 있는 입력 오류와 파일 오류를 확인했습니다.
빈 입력이나 범위를 벗어난 숫자는 조건문으로 미리 확인하고, 실행 중 발생할 수 있는 예외는 `try/except`로 처리합니다.

| 상황 | 처리 방법 | 처리 결과 |
| --- | --- | --- |
| 빈 입력 | `strip()`과 조건문으로 확인 | 안내 메시지 출력 후 다시 입력받음 |
| 숫자 입력란에 문자 입력 | `int()` 변환 중 발생하는 `ValueError` 처리 | 안내 메시지 출력 후 다시 입력받음 |
| 허용 범위 밖 숫자 입력 | 최솟값과 최댓값을 조건문으로 확인 | 올바른 범위의 숫자를 다시 입력받음 |
| `state.json`이 없음 | `FileNotFoundError` 처리 | 기본 퀴즈로 새 파일을 만듦 |
| JSON 문법 또는 UTF-8 데이터가 손상됨 | `JSONDecodeError`, `UnicodeDecodeError`, `UnicodeEncodeError` 처리 | 안내 후 기본 퀴즈로 복구함 |
| JSON의 키, 자료형, 선택지 개수, 정답 범위가 잘못됨 | `KeyError`, `TypeError`, `ValueError` 처리 | 잘못된 데이터를 사용하지 않고 기본 퀴즈로 복구함 |
| JSON이 지나치게 깊게 중첩됨 | `RecursionError` 처리 | 안내 후 기본 퀴즈로 복구함 |
| 파일 또는 저장할 데이터가 너무 커서 메모리가 부족함 | `MemoryError` 처리 | 기본 데이터로 복구하거나 저장 실패를 안내함 |
| 파일 읽기 또는 쓰기 실패 | `OSError` 처리 | 오류를 안내하고 가능한 범위에서 실행을 계속함 |
| 입력 중 `Ctrl+C` 또는 입력 스트림 종료 | `KeyboardInterrupt`, `EOFError` 처리 | 가능한 범위에서 저장한 후 안전하게 종료함 |
| 퀴즈 또는 점수 기록이 없음 | 조건문으로 목록과 기록을 확인 | 상황에 맞는 안내 메시지를 출력함 |

저장에 실패한 경우 새로 추가한 퀴즈는 현재 실행 중에는 사용할 수 있지만, 파일에 기록되지 않았으므로 프로그램을 다시 실행하면 유지되지 않을 수 있습니다.

## 현재 처리하지 못한 특수 상황

아래 항목은 일반적인 프로그램 사용이나 과제의 최소 요구 범위를 벗어나는 특수한 경우입니다.

| 특수 상황 | 현재 결과 |
| --- | --- |
| JSON의 `true`를 정답이나 점수로 저장 | Python에서 `bool`이 `int`의 하위 자료형이므로 숫자로 잘못 인정될 수 있음 |
| 저장 중 전원 차단 또는 강제 종료 | 파일 저장을 완전히 마치지 못할 수 있음 |

Python이 `MemoryError`를 발생시킨 경우에는 처리하지만, 운영체제가 프로그램을 즉시 강제 종료할 정도로 메모리가 부족한 상황까지 복구를 보장할 수는 없습니다.
예상하지 못한 모든 예외를 한 번에 숨기지 않고, 현재 프로그램에서 복구 방법이 분명한 오류만 구체적으로 처리했습니다.
